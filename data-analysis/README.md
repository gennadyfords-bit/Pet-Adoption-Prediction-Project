# Анализ данных проекта Pet Adoption Prediction

Этот раздел содержит подробные выводы по результатам разведочного анализа данных (EDA).

## 1. Общий обзор датасета (п. 6.1)
* **Объем данных:** 14,993 строки. Этого достаточно для построения надежной модели.
* **Признаки:** 24 столбца, включая факторы возраста, породы, здоровья и медиаконтента.

## 2. Типы данных и структура (п. 6.2 - 6.4)
* **Целевая переменная (AdoptionSpeed):** Категориальная скорость (0–4), тип Тип int64.
* **Категориальные признаки:** (Type, Gender, Vaccinated и др.) представлены как int64. Это оптимально для большинства алгоритмов машинного обучения.
* **Текстовые данные:** PetID, RescuerID, Name, Description имеют тип object. Потребуют обработки или удаления перед обучением.
* **Количественные признаки:** Age, Fee, Quantity, VideoAmt, PhotoAmt — int64 (счетные величины).

## 3. Обработка пропусков и дубликатов (п. 6.5 - 6.12)
* **Пропуски в текстах:** 
    * Description (Описание): 13 пропусков (0.08%). Рекомендуется замена на "No description provided".
    * Name (Имя): 1,265 пропусков (8.44%). Рекомендуется замена на "Unnamed".
* **Дубликаты:** Полных дубликатов в датасете **не обнаружено**, что говорит о чистоте собранных данных.

## 4. Ключевые инсайты и статистика (п. 6.9 - 6.10)

### Возраст и аномалии (Age)
* **Дисбаланс:** Медианный возраст — всего 3 месяца (при среднем 10.4). Большинство животных — котята и щенки.
* **Выбросы:** Максимальный возраст 255 месяцев (21 год). 
* *Гипотеза:* Значение 255 может быть кодом для "возраст неизвестен".

### Стоимость пристройства (Fee)
* **Бесплатная адаптация:** Более 75% объявлений не требуют оплаты.
* **Асимметрия:** Максимальная цена — 3000. Высокий коэффициент асимметрии (8.92).

### Здоровье и медиаконтент
* **Здоровье:** Животные в основном здоровы (среднее 1.04).
* **Контент:** Фотографии есть почти у всех (медиана 3), видео — большая редкость (среднее 0.06). Наличие видео может быть сильным фактором для привлечения внимания.

## 5. Анализ зависимостей (п. 6.14)

### Мультиколлинеарность (Сильные связи)
Наиболее тесная связь наблюдается в медицинском блоке:
* **Vaccinated (Вакцинация) и Dewormed (Глисты):** **0.72** — самая сильная корреляция. 
* **Vaccinated и Sterilized (Стерилизация):** 0.47.
* **Dewormed и Sterilized:** 0.43.
* *Вывод:* Эти признаки избыточны. Для линейных моделей стоит объединить их в единый индекс "ухода" (Medical Check).

### Прочие зависимости
* **Gender (Пол) и Quantity (Количество):** 0.49. Вероятно, группы животных в одном объявлении часто состоят из особей одного пола.
* **Age (Возраст) и Breed1 (Порода):** -0.31. Породистых животных чаще выставляют в более раннем возрасте.

### Связь с целевой переменной (AdoptionSpeed)
Линейная корреляция Пирсона со всеми признаками крайне низкая (все < 0.15):
* Порода (Breed1): 0.11
* Возраст (Age): 0.10
* Тип животного: -0.09
* *Вывод:* Линейная зависимость между отдельными признаками и скоростью пристройства практически отсутствует.

## 6. Общий вывод и стратегия разработки

1. **Нелинейные модели:** Из-за отсутствия линейных связей (корреляция Пирсона близка к 0) лучше всего использовать ансамбли решающих деревьев: **Random Forest**, **XGBoost** или **CatBoost**. Они эффективнее находят сложные скрытые зависимости.
2. **Feature Engineering:** 
    * Объединить медицинские флаги в общий признак "Full Medical Check".
    * Создать бинарный признак "Платно/Бесплатно" на основе Fee.
3. **Проверка категорий:** Поскольку Breed и Color — это категории, их значимость стоит дополнительно проверить через критерий Хи-квадрат или расчет Feature Importance в лесах, так как корреляция Пирсона для них малоинформативна.
