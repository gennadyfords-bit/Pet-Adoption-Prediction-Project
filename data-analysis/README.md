# Описание данных и признаков
## Описание файлов
• train.csv — Табличные/текстовые данные для обучающей выборки.
• test.csv — Табличные/текстовые данные для тестовой выборки.
• sample_submission.csv — Пример файла для отправки решения в правильном формате.
• breed_labels.csv — Содержит Type (Тип) и BreedName (Название породы) для каждого BreedID. Тип 1 — собака, 2 — кошка.
• color_labels.csv — Содержит ColorName (Название цвета) для каждого ColorID.
• state_labels.csv — Содержит StateName (Название штата/региона) для каждого StateID.

## Поля данных (Data Fields)
• PetID — Уникальный хеш-идентификатор профиля питомца.
• AdoptionSpeed — Категориальная скорость пристройства (адопции). Чем ниже значение, тем быстрее животное нашло дом. Это целевая переменная для предсказания. См. раздел ниже для получения дополнительной информации.
• Type — Тип животного (1 = собака, 2 = кошка).
• Name — Имя питомца (пусто, если имени нет).
• Age — Возраст питомца на момент подачи объявления, в месяцах.
• Breed1 — Основная порода питомца (см. словарь BreedLabels).
• Breed2 — Вторая порода, если питомец смешанной породы (см. словарь BreedLabels).
• Gender — Пол питомца (1 = самец, 2 = самка, 3 = смешанный, если профиль представляет группу животных).
• Color1 — Цвет 1 питомца (см. словарь ColorLabels).
• Color2 — Цвет 2 питомца (см. словарь ColorLabels).
• Color3 — Цвет 3 питомца (см. словарь ColorLabels).
• MaturitySize — Размер во взрослом возрасте (1 = маленький, 2 = средний, 3 = крупный, 4 = очень крупный, 0 = не указан).
• FurLength — Длина шерсти (1 = короткая, 2 = средняя, 3 = длинная, 0 = не указана).
• Vaccinated — Питомец вакцинирован (1 = да, 2 = нет, 3 = не уверен).
• Dewormed — Питомец прошел дегельминтизацию (обработан от глистов) (1 = да, 2 = нет, 3 = не уверен).
• Sterilized — Питомец стерилизован/кастрирован (1 = да, 2 = нет, 3 = не уверен).
• Health — Состояние здоровья (1 = здоров, 2 = легкая травма, 3 = серьезная травма, 0 = не указано).
• Quantity — Количество питомцев, представленных в профиле.
• Fee — Плата за пристройство (0 = бесплатно).
• State — Расположение (штат) в Малайзии (см. словарь StateLabels).
• RescuerID — Уникальный хеш-идентификатор спасателя/опекуна.
• VideoAmt — Общее количество загруженных видео для этого питомца.
• PhotoAmt — Общее количество загруженных фотографий для этого питомца.
• Description — Текстовое описание профиля питомца. Основной используемый язык — английский, некоторые описания на малайском или китайском.

## Целевая переменная (AdoptionSpeed)
Участникам необходимо предсказать это значение. Оно определяется тем, как быстро (если вообще это произошло) животное нашло дом. Значения устанавливаются следующим образом:
• 0 — Питомец был пристроен в тот же день, когда было опубликовано объявление.
• 1 — Питомец был пристроен в период от 1 до 7 дней (1-я неделя) после публикации.
• 2 — Питомец был пристроен в период от 8 до 30 дней (1-й месяц) после публикации.
• 3 — Питомец был пристроен в период от 31 до 90 дней (2-й и 3-й месяцы) после публикации.
• 4 — Питомец не был пристроен спустя 100 дней после публикации (в данном наборе данных нет животных, которые ждали бы пристройства в интервале между 90 и 100 днями).

## Изображения (Images)
Для питомцев, у которых есть фотографии, файлы названы в формате PetID-ImageNumber.jpg. 
• Image 1 — это основное фото профиля, установленное по умолчанию.
• Приватность: Лица людей, номера телефонов и адреса электронной почты на изображениях скрыты (замаскированы).

## Метаданные изображений (Image Metadata)
Изображения были обработаны с помощью Google Vision API. Этот анализ включает аннотации лиц, меток, текста и свойства самого изображения. 
• Формат файла: PetID-ImageNumber.json.
• Если определенное свойство (например, лица) не было обнаружено, оно будет отсутствовать в JSON-файле.
• Аннотация текста: Упрощена до одной записи всего найденного текста (вместо детальной разбивки по символам и словам). Контактные данные в тексте также анонимизированы.

## Данные о тональности текста (Sentiment Data)
Описания профилей питомцев были обработаны через Google Natural Language API для анализа эмоциональной окраски (тональности) и выявления ключевых сущностей.
• Формат файла: PetID.json.
• Важное примечание: Не все описания удалось проанализировать, поэтому файлов с данными о тональности меньше, чем общее количество строк в наборе данных.



# Анализ данных проекта Pet Adoption Prediction

Этот раздел содержит подробные выводы по результатам разведочного анализа данных (EDA).

## 1. Общий обзор датасета (п. 6.1)
* **Объем данных:** 14,993 строки. Этого достаточно для построения надежной модели.
* **Признаки:** 24 столбца, включая факторы возраста, породы, здоровья и медиаконтента.

## 2. Типы данных и структура (п. 6.2 - 6.4)
* **Целевая переменная (AdoptionSpeed):** Категориальная скорость (0–4), тип Тип int64.
* **Категориальные признаки:** (Type, Gender, Vaccinated и др.) представлены как int64. Это оптимально для большинства алгоритмов машинного обучения.
* **Текстовые данные:** PetID, RescuerID, Name, Description имеют тип object. Потребуют обработки или удаления перед обучением.
* **Количественные признаки:** Age, Fee, Quantity, VideoAmt, PhotoAmt — int64 (счетные величины).

## 3. Обработка пропусков и дубликатов (п. 6.5 - 6.12)
* **Пропуски в текстах:** 
    * Description (Описание): 13 пропусков (0.08%). Рекомендуется замена на "No description provided".
    * Name (Имя): 1,265 пропусков (8.44%). Рекомендуется замена на "Unnamed".
* **Дубликаты:** Полных дубликатов в датасете **не обнаружено**, что говорит о чистоте собранных данных.

## 4. Ключевые инсайты и статистика (п. 6.9 - 6.10)

### Возраст и аномалии (Age)
* **Дисбаланс:** Медианный возраст — всего 3 месяца (при среднем 10.4). Большинство животных — котята и щенки.
* **Выбросы:** Максимальный возраст 255 месяцев (21 год). 
* *Гипотеза:* Значение 255 может быть кодом для "возраст неизвестен".

### Стоимость пристройства (Fee)
* **Бесплатная адаптация:** Более 75% объявлений не требуют оплаты.
* **Асимметрия:** Максимальная цена — 3000. Высокий коэффициент асимметрии (8.92).

### Здоровье и медиаконтент
* **Здоровье:** Животные в основном здоровы (среднее 1.04).
* **Контент:** Фотографии есть почти у всех (медиана 3), видео — большая редкость (среднее 0.06). Наличие видео может быть сильным фактором для привлечения внимания.

## 5. Анализ зависимостей (п. 6.14)

### Мультиколлинеарность (Сильные связи)
Наиболее тесная связь наблюдается в медицинском блоке:
* **Vaccinated (Вакцинация) и Dewormed (Глисты):** **0.72** — самая сильная корреляция. 
* **Vaccinated и Sterilized (Стерилизация):** 0.47.
* **Dewormed и Sterilized:** 0.43.
* *Вывод:* Эти признаки избыточны. Для линейных моделей стоит объединить их в единый индекс "ухода" (Medical Check).

### Прочие зависимости
* **Gender (Пол) и Quantity (Количество):** 0.49. Вероятно, группы животных в одном объявлении часто состоят из особей одного пола.
* **Age (Возраст) и Breed1 (Порода):** -0.31. Породистых животных чаще выставляют в более раннем возрасте.

### Связь с целевой переменной (AdoptionSpeed)
Линейная корреляция Пирсона со всеми признаками крайне низкая (все < 0.15):
* Порода (Breed1): 0.11
* Возраст (Age): 0.10
* Тип животного: -0.09
* *Вывод:* Линейная зависимость между отдельными признаками и скоростью пристройства практически отсутствует.

## 6. Общий вывод и стратегия разработки

1. **Нелинейные модели:** Из-за отсутствия линейных связей (корреляция Пирсона близка к 0) лучше всего использовать ансамбли решающих деревьев: **Random Forest**, **XGBoost** или **CatBoost**. Они эффективнее находят сложные скрытые зависимости.
2. **Feature Engineering:** 
    * Объединить медицинские флаги в общий признак "Full Medical Check".
    * Создать бинарный признак "Платно/Бесплатно" на основе Fee.
3. **Проверка категорий:** Поскольку Breed и Color — это категории, их значимость стоит дополнительно проверить через критерий Хи-квадрат или расчет Feature Importance в лесах, так как корреляция Пирсона для них малоинформативна.
