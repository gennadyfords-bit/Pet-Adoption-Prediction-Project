# Pet-Adoption-Prediction-Project
Pet Adoption Prediction Project
# Описание
В основе проекта лежать данные платформы PetFinder.my. PetFinder.my с 2008 года является ведущей платформой по защите животных в Малайзии, с базой данных, насчитывающей более 150 000 животных. PetFinder тесно сотрудничает с любителями животных, СМИ, корпорациями и глобальными организациями в целях улучшения благополучия животных. Задача проекта Pet-Adoption-Prediction-Project - предсказание вероятности того, что питомца заберут из приюта
# Стек технологий
Python, Pandas, SQLAlchemy, OracleDB
# Нарабатываемые навыки
Клонирование репозитория, установка зависимостей
